## Notable gaps (no test case in this project covers these at all)

- **Spillway flow (`QSP`, the `SPQ`/`SPH` rating-curve path, gated by `HSP`)**: none of the 5 provided examples set `HSP` to a value that triggers this path (`INTPSP` is exercised trivially every timestep since the code always attempts the lookup, but `QSP` never becomes materially nonzero in any dataset checked). **No test in this project exercises a real spillway-flow scenario.**
- **Cohesive erosion specifically isolated from noncohesive**: every dataset blends `D50C`/`D50S` etc. via the `FK1`/`FK2` weighting (`original/SRC/Breach.for` lines ~453-481), so cohesive-only or noncohesive-only erosion paths were never isolated and confirmed independently — marked `UNKNOWN` throughout rather than guessed.
- **Slope/slump failure (`SUBROUTINE SLUMP`, `KSLUMP`)**: never specifically confirmed triggered or not in any dataset's log — the state-transition diagnostic tracks `KREG`/`KG`, not `KSLUMP`, so this would need separate instrumentation not built in this session.
- **Pipe roof collapse (`KREG=5`)**: not observed in any of the 5 provided examples or targeted tests (`TETON`/`LAWN` transition piping→open breach directly via `OPEN_BREACH_TRANSITION`, never through `KREG=5`). No test in this project exercises the deep-seated-collapse code path at all.
- **A true post-breach reservoir depletion-then-refill cycle**: attempted at length (`docs/RESERVOIR_REFILL_TEST.md`), not achieved.
- **Deterministic-repeatability checks (20× or more repeated runs)** were only done for `negative_bmx.dat` and (informally, via the timestep-convergence sweep's 3-repeat consistency checks) `dth_1p0em3`/`dth_1p0em5` on BSMBOT2. The other 4 real examples were confirmed reproducible only via single-run byte-for-byte diffs across multiple *sessions* (this session's fresh-rebuild checks), not a dedicated 20-repetition loop each.
