## 2. Related/supporting variables worth noting

| Variable | Role |
|---|---|
| `NSPH` (`COMMON/CNSPH/`, L80) | Actual count of valid `(SPQ,SPH)` spillway-rating pairs — computed in `RDDATA` L1657-1663 by scanning for the first non-increasing `SPH(I)`. This is the existing pattern `NHSA`/`NCS` should mirror. |
| `ASTW(8)` (`COMMON/CSTW/`) | Cumulative cross-section area table, built from `BSTW`/`HSTW` in `RDDATA` L1604-1609 (`DO 208 I=2,8`, unconditional over all 8 slots) — feeds `TWSEC`. |
| `HI`, `HU`, `HL`, `HPI`, `HSP` | All elevations (`COMMON/EL/`): initial pool, dam crest, valley-floor/base datum, initial pipe centerline, spillway crest. |
| `SUB`, `SUBOLD`, `CV` | Submergence correction factor (current/previous) and velocity-head correction applied to `QB` near L1294-1299. |
| `QQQ` | Total flow (`QB+QSP+QT`) used to size the tailwater rating search in the `TWSEC` loop (L1288-1289). |
| `KPIP`, `KPT` | Piping-active flag and piping-just-transitioned-to-weir flag; gate which `HEAD`/`TWD` branch executes. |
| `KNAT` | Natural (landslide) dam flag (`ZD>4.0` ⇒ `KNAT=1`), changes several geometry formulas (e.g. slump side, `HVT` progression). |

## 3. Implicit-typing findings (documentation only — no `IMPLICIT NONE` added)

No explicit `IMPLICIT NONE` or type declarations exist anywhere in the file; every variable's type follows the classic FORTRAN default (`I,J,K,L,M,N…` prefixed ⇒ INTEGER, all else ⇒ REAL). Variables of note that rely entirely on this implicit rule (i.e., never explicitly declared `INTEGER`/`REAL` anywhere): `KREG, KPIP, KPT, KNAT, KCOL, KQ, KQ1, KREC, NFIL, NFAIL, IFIL, NHP, NSPH, I, K, L, KIT, KSLUMP, KSLMPC, ILOOP, ITW, KG(local to PLOT)`. `gfortran -std=legacy` accepts this without complaint (confirmed — zero warnings on the reference build). No `-Wimplicit` issues were raised by the `-Wall -Wextra` diagnostic build either, because the file never mixes an integer-prefixed name with real arithmetic in a way gfortran flags. Full variable-by-variable "used-before-assigned" sweep is tracked as a `-fcheck=all`/`-Wall` diagnostic task under BRCH2018-07 in `CHANGE_MATRIX.md`, not repeated here.
